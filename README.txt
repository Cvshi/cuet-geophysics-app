CUET PG GEOPHYSICS — PYQ UPDATE V1

This is a separate update package for the PYQ section.
Keep PYQs separate from questions.json.

Files:
- pyq_update.json
- README.txt

The manifest includes verified source links and a few 2024 worked examples.
The examples use concise summaries rather than reproducing entire copyrighted papers.

To build a complete exact-text PYQ bank, upload the question-paper PDFs in the chat; user-provided files can then be processed into pyq.json.

Recommended app structure:
questions.json = original/generated practice
pyq.json = verified real PYQs
PYQ Mistake Bank = only previously missed PYQs

Rules:
- Fresh PYQ practice never repeats attempted PYQs.
- Mistaken PYQs repeat only in PYQ Mistake Practice.
- Prefer NTA final answer keys as authoritative.
